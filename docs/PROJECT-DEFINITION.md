# DevOrchestra 제품 정의

Windows 로컬 개발 관리 앱이다. 사용자는 프로젝트별 목표·지침·모델·추론·권한·시간·토큰·비용을 정하고, 관리자 → 개발자 → 검토자 → 결정적 검증기 → 관리자 판정을 순서대로 실행한다. 승인, 중단, 결과 확인은 사용자가 통제한다.

P1의 단위는 단일 사용자 프로필의 합성 프로젝트와 합성 작업이다. 카탈로그는 두 개의 합성 프로젝트 계약을 코드에 제공하며, 각 실행은 계약의 스냅샷을 보존한다. 실제 프로젝트 등록·편집, 사용자 인증과 검증된 OS 격리는 후속 단계다.

## 시각 콘솔

프로젝트 카드, 단계 진행 표시, 역할 패널, 예산 수치, 이벤트 패널은 검증된 원장에서 읽는다. 단계 진행은 완료 이벤트에 근거하며 임의의 퍼센트나 추정 활성 상태를 표시하지 않는다. 실제 시스템 상태는 결정적 상태 전이, 모델 설명은 별도로 표시할 비신뢰 제안, 색·아이콘은 장식, 근거 데이터는 감사 이벤트·테스트·Git·승인·계측 레코드다. Mock 결과와 합성 토큰에는 명시적으로 출처를 표시한다.

P1 인수 기준은 [아키텍처](ARCHITECTURE-ROADMAP.md)와 [현재 상태](CURRENT-STATUS.md)에 기록한다.

## 게임형 UI 최종 요구 (2026-11-08)

Windows 콘솔은 프로젝트 진행과 역할별 상태·실행 기록을 게임형 운영실처럼 시각화한다. 단, 실제 검증 원장·상태 전이·확인된 Git/테스트·사용량만 표시하고, 데모·합성 수치는 분리한다. 전체 진행도는 근거가 있는 milestone만 표시한다. 전역 단일 실행을 시각화에서도 유지하고 역할별 상세 감사로 내려갈 수 있게 한다. [GAME-UI-DESIGN](GAME-UI-DESIGN.md) 준수. 실제 구현은 P1.5/P2 이후이고 P2 OS 보안 검증보다 우선하지 않는다.
