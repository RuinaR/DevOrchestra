# Windows x64 릴리스 검증표

| 경로 | 확인 기준 |
|---|---|
| 설치와 업데이트 | 새 Windows 11 x64 표준 계정에서 Python 없이 ZIP을 풀고 EXE를 실행한다. 사용자 저장소를 초기화한 뒤 다른 버전 폴더에서 열어 기존 상태를 확인한다. |
| UI | 100%, 125%, 150% 배율과 작은 창에서 초기 설정, 계정, 프로젝트, 승인 화면의 스크롤과 Tab, Enter, Esc를 확인한다. |
| 도구 | ZIP 미선택, 다른 버전, 손상된 ZIP을 안내하고 공식 고정 ZIP의 해시와 서명을 확인한다. Git이 없으면 안내를 표시한다. |
| 인증 | 별도 ChatGPT 계정으로 브라우저 로그인, 취소, 만료 또는 네트워크 오류, 로그아웃 및 계정 교체를 확인한다. 제공자 모델 목록과 사용률 조회 실패를 정상 구독 연결과 구분한다. |
| 프로젝트 | 권한 없는 원본은 거부하고, 미커밋 파일이 있는 Git 원본을 보존하면서 승인된 별도 복제본에서 작업한다. |
| 자동 개발 | 별도 승인으로 실제 Codex 역할, 중간 취소, 소프트 예산 및 제공자 제한, 비정상 종료와 Job 회수, 재시작 후 미확정 원장, 재개를 관측한다. |
| 원본 반영 | 변경 diff와 독립 검증을 대조한 뒤 별도 승인 화면의 거부 및 원본 충돌 시 무변경을 확인한다. |
| 게시 전 확인 | ZIP과 EXE 해시, 내장 Tk/리소스, 배포 라이선스, 코드 서명 상태, 비공개 데이터 제외, 게시 승인 확인. |

신규 온라인 종단 간 검증은 계정 소유자가 공식 브라우저에서 로그인한 후 별도 승인으로 실행한다. 로컬 합성 Code Mode 검사와 기존 온라인 세션 기록은 각각의 관측 범위에 한정한다.

## 0.3.0 후보에서 관측한 결과

- Windows 11의 격리된 사용자 데이터 폴더와 System32만 포함한 PATH에서 ZIP의 EXE를 실행했다. 첫 설정 창을 열고, 준비한 동일 저장소를 별도 압축 해제 폴더의 EXE로 다시 열었다. 두 실행의 소유 Job과 임시 경로를 정리했다.
- Codex 환경 화면은 Tk 배율 100%, 125%, 150%로 렌더링해 버튼 표시를 확인했다. 실제 OS DPI 변경, 전 화면 스크롤·키보드·모달 탐색은 검증 대기다.
- 빈 저장소에서 고정 ZIP 가져오기, 로그인 전 상태, 서명된 Git 및 모델 없는 로컬 Code Mode 실행을 확인했다. 등록 프로젝트의 Windows 통합 회귀와 저장소 회귀가 통과했다.
- 별도 Windows 계정 로그인·교체, 해당 계정의 모델·제공자 한도, 첫 온라인 자동 개발과 중단·재개는 검증 대기다. 공개 파일 인덱스 검사와 과거 Git 이력의 자격증명 경로·키 형식 표본 검사를 수행했다.

## 릴리스 적합성 판정

| 항목 | 판정 | 근거 또는 남은 단계 |
|---|---|---|
| 포터블 실행 | REAL_PASS | 실제 Windows EXE에서 첫 설정 창과 종료를 관측했다. 시험 프로세스 PATH에는 System32만 넣었다. |
| 신규 사용자 설정 | REAL_PASS | 현재 Windows 계정의 빈 데이터 폴더에서 사용자 저장소, 고정 Codex ZIP, 로그인 전 상태, Git 탐색을 확인했다. 별도 Windows 계정 검증은 남아 있다. |
| 새 계정 공식 로그인·모델 및 한도 조회 | NOT_VALIDATED | 계정 소유자가 공식 브라우저에서 직접 연결한 뒤 확인한다. |
| 새 계정 온라인 자동 개발 | NOT_VALIDATED | 독립 Git 프로젝트에서 별도 모델 호출 승인 후 확인한다. |
| 단일 슬롯 및 원본 Git 보호 | REAL_PASS | 소유 Job과 검증 결과를 확인하고, 독립 Git 복제본 검증에서 원본 파일과 미커밋 변경을 비교한다. |
| 소프트 예산 종료 | SYNTHETIC_PASS | 시간·토큰 및 마무리 예산 회귀를 사용한다. |
| 중단 후 검토 재개 | SYNTHETIC_PASS | 대체 모델 응답으로 정착한 세션의 재개와 중복 실행 차단을 확인한다. 신규 계정의 온라인 중단 및 재개는 검증 대기다. |
| 업데이트와 상태 재사용 | REAL_PASS | 서로 다른 압축 해제 폴더의 실제 EXE로 같은 시험 사용자 저장소를 다시 열었다. |
| UI 접근성과 안정성 | NOT_VALIDATED | 첫 실행과 Tk 배율별 연결 화면을 관측했다. 전체 모달, 실제 OS DPI 전환, 키보드 탐색은 검증 대기다. |
| 비공개 정보 제외 | REAL_PASS | ZIP 항목과 EXE 내장 항목을 검사한다. |
| 라이선스·서명·게시 | BLOCKED | ZIP, 해시와 릴리스 노트를 준비했다. EXE는 미서명 상태이며, 제품 라이선스와 공개 게시 여부는 소유자 결정 대기다. |
